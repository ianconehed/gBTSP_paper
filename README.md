# gBTSP\_paper

Code and data for the paper "Theoretical Frameworks of Credit Assignment via Behavioral Timescale Synaptic Plasticity", (Cone, Clopath, Ponte Costa 2026).



This code is located in the folder CODE. Each figure file (e.g., Figure1.m, Figure2\_1d.m) can be run independently to replicate the results from the paper. Each should produce multiple figures, including the subfigures used in the paper. The code was created with MATLAB (version 2023b) and tested on Windows machines. Runtime should be <5 minutes on a laptop or desktop computer for any individual figure, barring Figure 5, which takes \~15 minutes.



All produced data is stored in the DATA folder in .mat format.
